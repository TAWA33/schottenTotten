# Schotten Totten – Java Project

Command-line implementation of the board game **Schotten Totten** by Reiner Knizia, in Java.

## Rules

Two players. 9 stones. Each stone is won by the best 3-card combination:

| Combination | Value |
|---|---|
| Straight flush | 5000+ |
| Three of a kind | 4000+ |
| Flush | 3000+ |
| Straight | 2000+ |
| Sum | 1000+ |

**Win:** control **5 stones** or **3 adjacent stones**. Tie on a stone → first player to complete wins.
